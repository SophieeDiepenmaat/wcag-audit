# WCAG audit – GameShop Twente

Voor deze opdracht heb ik de toegankelijkheid van [GameShop Twente](https://gameshop-twente.nl/) onderzocht met Lighthouse. De homepage scoort **94 op desktop** en **93 op mobiel**.

Uit de test komen twee problemen naar voren: sommige teksten hebben te weinig contrast en sommige links hebben geen herkenbare naam. Knoppen hebben volgens de test wel een toegankelijke naam en formuliervelden hebben labels.

De handmatige tests moet ik nog uitvoeren. De resultaten en screenshots van de Lighthouse-test staan in [mijn Wiki](https://github.com/SophieeDiepenmaat/wcag-audit/wiki).
